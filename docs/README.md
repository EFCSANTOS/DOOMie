# DOOMie Knowledge Base

Topic docs for the DOOMie fork of DOOM (Linux DOOM 1.10). Start with
[../CLAUDE.md](../CLAUDE.md) for build steps, conventions, and invariants.

| Doc | Read it when you're... |
|---|---|
| [architecture.md](architecture.md) | getting oriented: the main loop, the tic model, and the module map |
| [rendering.md](rendering.md) | changing anything that draws: BSP, walls, visplanes, sprites |
| [playsim.md](playsim.md) | changing game logic: thinkers, mobjs, collision, AI, specials |
| [data-and-memory.md](data-and-memory.md) | changing WAD loading, lumps, or the zone allocator |
| [networking.md](networking.md) | changing netcode, demos, or the IPX/serial drivers |
| [building-and-porting.md](building-and-porting.md) | building on a modern system or porting to a new platform |
| [fork-notes.md](fork-notes.md) | recording or looking up what DOOMie changed from upstream |
